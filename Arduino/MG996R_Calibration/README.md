# MG996R 각도 보정 — Arduino IDE만 사용

1. MG996R의 신호선을 Arduino **D9**에 연결합니다. 서보 전원은 전류를 감당하는 별도 **5–6 V** 전원으로 공급하고 전원 GND와 Arduino GND를 공통으로 연결합니다. 서보 전원을 D9에서 공급하지 않습니다.
2. `MG996R_Calibration.ino`를 Arduino IDE에서 열어 업로드합니다. 부팅 시에는 움직이지 않습니다.
3. Arduino IDE **시리얼 모니터**를 열고 속도를 **115200 baud**, 줄바꿈을 **새 줄(Newline)**로 설정합니다. 같은 포트를 쓰는 ROS 브리지는 종료합니다.
4. 입력창에 `90`을 입력하고 **전송/Enter**를 누릅니다. 이 첫 명령으로 D9 제어가 시작됩니다. 그다음 `+`/`-`는 1°씩, `]`/`[`는 5°씩 이동합니다. `0`부터 `180`까지 숫자를 입력하면 해당 각도로 이동합니다. `?`는 현재 명령 각도, `off`는 서보 신호 끄기입니다.
5. 시리얼 모니터의 `ANGLE`에서 해지·체결에 맞는 서로 다른 두 각도를 기록합니다. 도킹 스케치의 `UNDOCKED_ANGLE`, `DOCKED_ANGLE`에 그 값을 입력하고 도킹 스케치를 다시 업로드합니다.

`ANGLE`은 **명령한 각도**입니다. 일반 MG996R에는 실제 축 각도를 읽는 피드백선이 없습니다. 좁은 기구에서는 `0`이나 `180`을 바로 명령하지 말고 작은 간격으로 움직이며 기구 간섭을 확인하세요.

`ANGLE`은 바뀌는데 축이 움직이지 않으면 서보의 별도 전원, 공통 GND, D9 신호선, Arduino IDE 보드·포트 선택을 확인하세요. 시리얼 모니터에 아무 응답이 없다면 115200 baud와 새 줄 설정을 확인하세요.
